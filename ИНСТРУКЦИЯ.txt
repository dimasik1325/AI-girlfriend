💜 AI GIRLFRIEND — ИНСТРУКЦИЯ ЗАПУСКА
==========================================

1. Распакуй архив в любую папку (например, на Рабочий стол)
2. Дважды кликни по файлу "запустить.bat" (или START.bat — это одно и то же)
3. Что произойдет автоматически:
   [1/3] Проверка Python — если он уже установлен, пункт пропускается
   [2/3] Если Python нет — скачается Python 3.12.7 (~25 МБ) и тихо установится
   [3/3] Запустится сервер и откроется браузер с твоей девушкой

4. Сайт откроется по адресу: http://localhost:8000
   Не закрывай черное окно пока общаешься!
   Чтобы остановить — просто закрой окно bat-ника.

ЧАСТЫЕ ВОПРОСЫ:
----------------
- Антивирус ругается? — Это обычный Python сервер, нажми "Разрешить"
- Порт 8000 занят? — bat сам найдет свободный (8001, 8002...)
- Python не нашелся после установки? — Перезапусти bat еще раз (нужно обновить PATH)
- Хочешь открыть вручную? — После запуска сервера просто открой в браузере http://localhost:8000
- Без интернета работает? — Да, кроме первоначальной загрузки Python

НАСТРОЙКИ В САЙТЕ:
------------------
Шестеренка в углу → можно:
- Поменять ей имя и как она зовет тебя
- Выбрать характер (Нежная, Страстная, Игривая и т.д.) и тонко настроить слайдерами
- Нажать "Очистить переписку" чтобы начать заново (прогресс сохранится в браузере)
- Сбросить всё полностью

Все сохраняется автоматически в браузере, даже если закрыть вкладку.
