# AI Girlfriend 💜

Сайт, где ты общаешься с нейросетью, которая играет роль твоей девушки.
Сначала ты рассказываешь о себе, потом придумываешь ей имя (или выбираешь из предложенных),
настраиваешь характер — страсть, любовь, игривость, ревность, юмор, инициативу — и начинаешь
переписку, как с живым человеком: она помнит твоё имя, реагирует на настроение, а её аватар
меняется в зависимости от того, что она чувствует.

## Как это работает

1. **Шаг 1 — «Ты»**: вводишь своё имя, чтобы она к тебе обращалась.
2. **Шаг 2 — «Её имя»**: сайт предлагает варианты имён (похожие на то, что ты введёшь) или принимает своё.
3. **Шаг 3 — «Характер»**: шесть ползунков и шесть типажей (нежная, игривая, цундере, загадочная, заботливая, дерзкая).
4. **Шаг 4 — «Нейросеть»**: ключ подхватывается **автоматически** — проверяется сервер, затем ключ в браузере;
   если ключа нет, включается встроенный офлайн-движок, и сайт работает сразу, без интернета.
5. **Чат**: реплики уходят в модель вместе с системным промптом-личностью и историей переписки,
   действия она пишет `*в звёздочках*`, а озвучка её сообщений идёт голосом браузера (можно выключить кнопкой 🔊).

## Подключение нейросети (автовыбор ключа)

Приоритеты автоопределения:

1. **Ключ на сервере** — `.env` рядом с `server.js`:
   ```bash
   cp .env.example .env   # и заполни LLM_PROVIDER + LLM_API_KEY
   npm start
   ```
   Тогда сайт шлёт запросы через `POST /api/chat`, и ключ не светится в браузере.
2. **Ключ в браузере** — вставляется на шаге 4 или в «⚙ Настройки» и хранится в `localStorage`.
   Запросы уходят провайдеру напрямую.
3. **Ключ в ссылке** — `?key=sk-...&provider=openai` для демо.
4. **Встроенный офлайн-движок** (`js/local.js`) — отвечает по правилам с учётом имени и ползунков,
   понимает приветствия, «люблю», «скучал», «прости», ревность и т.д., запоминает факты о тебе.

Поддерживаются провайдеры с OpenAI-совместимым API: **OpenAI**, **OpenRouter**, **Groq**.
Текущий режим виден в чате под аватаром («движок: …»).

## Запуск

```bash
npm start          # http://localhost:3000 (сервер без зависимостей, только Node >= 18)
```

Можно открыть `index.html` и без сервера — статика работает как есть,
просто не будет серверного прокси `/api/chat`.

## Тесты

```bash
npm test           # node --test, 51 тест: провайдеры, промпт, офлайн-движок, стор, сервер, UI-связка
```

## Структура

```
server.js        статика + /api/health, /api/config, /api/chat (прокси LLM)
index.html       мастер создания (4 шага) + чат
styles.css       неон-аниме оформление, адаптив
js/prompt.js     сборка системного промпта из ползунков и памяти
js/providers.js  OpenAI/OpenRouter/Groq + автовыбор рабочего ключа
js/local.js      офлайн-движок, предложения имён, память фактов
js/store.js      localStorage: профиль, история, память, ключи
js/app.js        UI: шаги, чат, аватары по настроению, озвучка
assets/her/      четыре аватара-настроения: smile, shy, flirt, sad
test/            node:test без зависимостей
```

## Про контент

Это романтический компаньон: флирт, нежность, ревность и страсть — да,
откровенно порнографический текст — нет (это зашито прямо в системный промпт).
