# 💜 AI Girlfriend — Твоя девушка, которая всегда рядом

Живой сайт-чат с AI девушкой, которая ведёт себя как реальная: **пишет сама**, скучает, задаёт вопросы, помнит всё о тебе, ревнует, флиртует и заботится.

Открой сайт → выбери имя и характер → начни историю. При закрытии вкладки **весь прогресс сохраняется** автоматически в браузере.

🌐 **Live Preview:** запусти `python3 -m http.server 8000` и открой `index.html` — никакого бэкенда не нужно.

---

## ✨ Что умеет

- **Живое общение как с реальной девушкой** — отвечает мгновенно, с эмоциями и эмодзи, задаёт встречные вопросы
- **Пишет сама** — если ты долго молчишь (70-150 сек), она напишет первая: «Ты куда пропал? Я соскучилась 🥺»
- **Спрашивает** — «Как прошёл день?», «Скучал по мне?», «Чем занимаешься?»
- **Помнит всё** — имя, интересы, факты из переписки (раздел «Что она помнит о тебе»)
- **Настрой характер**: 6 пресетов + 6 слайдеров
  - 💗 Нежная • 🔥 Страстная • 😏 Игривая • 🌸 Скромная • 😈 Дерзкая • 🫶 Заботливая
  - Тонкая настройка: Нежность / Страсть / Игривость / Юмор / Забота / Ревность
- **Дай ей имя** — и выбери, как она называет тебя
- **Выбор аватара** — 6 образов
- **Сохранение прогресса** — вся переписка, уровень отношений, воспоминания в `localStorage`. Закрыл вкладку — открыл и продолжил.
- **В настройках можно:** очистить переписку, сбросить всё, экспортировать чат в JSON
- **Уровень отношений** — от «Знакомство» до «Душа в душу», растёт с каждым сообщением
- **Подарки** 🌹🍫🧸💍 — дари ей цветы, шоколад, мишку, кольцо — она реагирует по-разному
- **Фото и голосовые** — иногда присылает фото, голосовые можно озвучить (Web Speech API)
- **Индикатор «печатает...»**, аватары, статусы «в сети», быстрые ответы, звуки (опционально)
- **Работает оффлайн** — встроенный движок без API ключей. Хочешь GPT-4o — вставь свой `sk-...` в настройках

## 🧠 Нейросеть (Gemini / ChatGPT)

- **По умолчанию — Бесплатный ИИ без ключа** (через Pollinations, модель OpenAI) — работает как ChatGPT, отвечает как реальная девушка: ты пишешь одно — она другое, помнит контекст 12 сообщений, характер и память
- **Gemini** — выбери в настройках и вставь ключ с https://aistudio.google.com/app/apikey (бесплатно)
- **ChatGPT** — вставь sk-... с platform.openai.com
- Если нейросеть не отвечает (нет интернета) — автоматом fallback на встроенный живой офлайн-движок (120+ шаблонов)
- Чат теперь **по центру, большой, не слева маленький** — сообщения 780px по центру, пузырьки 640px, кнопка скрыть панель для полного экрана

## 🛠 Технологии

- Чистый HTML / CSS / JS — один файл `index.html`, без сборки
- `localStorage` для сохранения прогресса
- Оффлайн-движок с 100+ шаблонами ответов, детекцией интентов, памятью и системой привязанности
- Опционально: OpenAI API (`gpt-4o-mini`) если указан ключ
- Адаптив: десктоп (sidebar + chat) и мобайл (drawer)

## 🚀 Запуск

```bash
# просто открой файл
open index.html

# или через сервер (для превью)
python3 -m http.server 8000
# -> http://localhost:8000
```

Никаких `npm install` не нужно.

## 🔒 Приватность

Всё хранится **только в твоём браузере**. Никакой сервер не видит переписку. Экспорт/импорт — локальный JSON.

## 🎨 Настройка характера

В модалке «Настроить»:
- Имя девушки / твоё имя
- Аватар
- Пресет характера (влияет на стиль ответов)
- Слайдеры черт — реально меняют фразы (при высокой ревности — ревнует, при высоком юморе — шутит и т.д.)
- Тогглы: «Пишет сама», «Печатает...», «Звуки»
- Поле для OpenAI ключа
